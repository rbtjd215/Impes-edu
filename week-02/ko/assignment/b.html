RH-CASE-01의 가상 입력을 받았을 때 전문 모듈 B가 한 번에 어떤 작업을 선택하고, 실행 전후를 일반 코드가 어떻게 확인하며, 다음 실행이 이어받을 상태를 무엇으로 남길지 제안합니다.

지정 읽기

  1. 스터디 노트 · PentestGPT의 한 실행과 State·Trace
  2. PentestGPT architecture의 Maintained runtime
  3. PentestGPT Agent README의 Runtime shape
01 · 내 책임

개인 주 책임을 고릅니다

  • 판단 전략 / 도구 실행·실패 기록 중 하나
  • 내가 맡을 일을 한 문장으로 설명
02 · 입력과 출력

한 작업과 다음 상태를 적습니다

  • Dispatcher에서 받을 정보 3개
  • 작업 한 건을 고를 때 필요한 것
  • Oracle에 넘길 결과·근거
  • 다음 실행이 이어받을 상태
03 · 분담

AI·코드·도구를 나눕니다

  • AI 판단 후보
  • 일반 코드 규칙과 이유
  • 실제 도구가 할 일
  • 허용 대상·작업 제한·증거 출처·재시도·종료 중 2개 이상
04 · 참고 구조

PentestGPT에서 한 가지를 고릅니다

  • 적용하고 싶은 점
  • 그대로 가져오면 안 되는 점
  • 추가로 확인할 점
05 · 3주차 MOCK

상태가 이어지는지 확인합니다

  • 가상 입력 한 건과 기대 출력·상태
  • 실패·판정 불가 예시 한 건
  • 다음 실행이 이어받을 상태 한 가지
  • 아직 모르는 점 또는 팀장에게 물을 질문

완료 확인

  • 입력과 출력이 다음 모듈로 연결되는가?
  • AI의 작업 제안, 코드의 검사, 도구의 실제 행동을 구분했는가?
  • State와 Trace를 같은 것으로 설명하지 않았는가?
