# IMPES RedHarness 교육자료

2026년 2학기 RedHarness 동아리의 학생용 공개 자료 저장소입니다.

## 공개 범위

- 주차별 교육 슬라이드
- 학생용 과제
- 교육 대시보드

운영 기록, 발표 대본, 정답, 팀 역할표와 프로젝트 내부 문서는 이 저장소에 올리지 않습니다.

## 자료 추가 규칙

각 주차 자료는 `week-01`부터 `week-08`까지의 폴더에 `index.html`로 올립니다. 해당 파일이 GitHub Pages에 배포되면 대시보드의 주차 버튼이 자동으로 활성화됩니다.

```text
index.html
week-01/index.html
week-02/index.html
...
week-08/index.html
```
