# IMPES · RedHarness 교육자료

2026년 2학기 IMPES 동아리에서 진행하는 RedHarness 프로젝트의 교육자료입니다.

->> [교육 사이트 바로 가기](https://rbtjd215.github.io/Impes-edu/)

## RedHarness 소개

RedHarness는 AI 에이전트가 도구를 사용해 로컬 웹 보안 실습 문제를 해결하고,
실행 결과와 판단 근거를 기록하는 시스템을 만드는 교육 프로젝트입니다.

AI 에이전트의 기초를 배우고, 기존 보안 에이전트의 구조를 살펴보며,
모듈 설계와 구현부터 결과 검증까지 단계적으로 경험합니다.

## 주요 학습 내용

- AI 에이전트와 하네스의 기본 개념
- 웹 보안 실습과 도구 사용
- 모듈 설계와 프로젝트 통합
- 실행 결과 검증과 성공·실패 근거 기록

주차별 슬라이드와 학습 자료는 교육 사이트에서 확인할 수 있습니다.
